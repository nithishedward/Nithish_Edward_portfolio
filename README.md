## 🚀 Featured Projects

### 01. JARVIS — Local AI Voice Assistant

A Windows-based voice assistant that combines speech recognition, a locally running language model, and speech synthesis to support voice-driven computer interactions.

**Technologies:** Python · Ollama · Llama 3.2 · Whisper · OpenWakeWord · pyttsx3

**Key Features**
- Speech-to-text processing using Whisper.
- Local AI responses powered by Llama 3.2 through Ollama.
- Wake-word detection for hands-free activation.
- Voice responses and predefined Windows commands.

**Repository:** [github.com/nithishedward/jarvis-local-windows-assistant](https://github.com/nithishedward/jarvis-local-windows-assistant)
